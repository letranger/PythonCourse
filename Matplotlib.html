1. Matplotlib 簡介

1.1. Matplotlib 是什麼？

Matplotlib 是 Python 中一個非常流行的繪圖套件，主要用來產生各種 2D 圖表（也支援部份3D圖表）。這個工具讓我們可以用程式碼很容易地繪製各種類型的圖形，像是折線圖、長條圖、圓餅圖等。它在學術界和資料科學領域非常受歡迎，因為它強大的功能和簡單的使用方式。

1.2. 兩個重要模組：pylab 和 pyplot

  • pylab：這個模組實作了許多 Matlab 的功能，讓學術界的人能夠輕鬆轉換到 Python 上進行繪圖。pylab 可以被視為 Python 版的 Matlab 繪圖工具。
  • pyplot：這個模組在 pylab 的基礎上加入了 Numpy 支援，讓你可以先用 Numpy 進行數學計算，然後用 pyplot 繪製圖表。這樣你不僅可以進行數據分析，還能把結果視覺化。

1.3. 為什麼使用 Matplotlib？

  • 簡單易用：Matplotlib 的語法非常簡單，初學者可以輕鬆上手。
  • 圖形美觀：它能生成高品質且美觀的圖表。
  • 圖形類型多：除了基本的折線圖、長條圖，還支援更複雜的圖形像是直方圖、熱圖等。
  • 相容於 Matlab：Matplotlib 提供了類似 Matlab 的繪圖方式，對於有 Matlab 經驗的使用者來說，過渡到 Python 的 Matplotlib 會非常順暢。
  • 社群支援強大：Matplotlib 擁有龐大的使用者社群，遇到問題時可以很容易找到解決方案。

2. Matplotlib 基本語法

2.1. 基本語法:

在 Matplotlib 中，我們可以使用 matplotlib.pyplot 來繪製各種圖形。最常用的函式是 plt.plot()，它可以用來繪製折線圖、函數曲線等。

2.1.1. plt.plot()

  • 要使用 plt.plot() 繪製圖形，我們需要先匯入 matplotlib.pyplot，並使用 plot() 函式來繪製資料點的連接線條。
  • 語法: plt.plot([x座標資料,] y座標資料 [, 參數1, 參數2, …])
  • plt.plot()官網說明

2.1.2. plt.show() 函式

  • 用來顯示圖形，是每次繪圖後都需要呼叫的函式。當你呼叫這個函式後，圖形會顯示在螢幕上。
  • 如果你是用PyCharm等IDE，請務必在每次繪圖後呼叫 plt.show()，否則圖形不會顯示出來。
  • 如果你在 Jupyter Notebook 或 Colab 中使用 Matplotlib，通常不需要特別呼叫 plt.show()，因為圖形會自動顯示出來。

2.1.3. plt.savefig()

  • plt.savefig()，()裡可以指定檔案名稱和格式，用來將繪製的圖形儲存為圖片檔案，還能指定解析度。
  • plt.savefig()官網說明

如果你想將繪製的圖表儲存到檔案，可以使用 plt.savefig() 函式，它允許你指定檔案路徑和解析度來儲存圖片。

2.3. plot 官方語法

plot()函式控制輸出主要有以下兩類參數：

  • fmt 字串
  • kwarg 參數

基本語法如下:

  • plot([x], y, [fmt], *, data=None, **kwargs)
  • plot([x], y, [fmt], [x2], y2, [fmt2], …, **kwargs)

3. 參數控制

在 Matplotlib 中，我們可以透過 fmt 字串和 kwarg（keyword argument）來控制圖形的外觀。這些參數可以幫助我們設置線條顏色、標記、線型以及其他視覺元素，使得繪製的圖形更加美觀且具有區分性。以下介紹如何使用 fmt 字串和 kwarg 參數來自定義圖表。

3.1. fmt 控制參數

fmt 是一個簡便的字串格式，用來設定線條的顏色、標記和線型。通過簡單的字元組合，我們可以快速控制圖形的基本格式。

3.1.1. 基本語法

plt.plot(x座標, y座標, 'fmt')

fmt 字串由三個部分組成，依序為 [顏色][標記][線型] ，三者皆為可選，可任意組合：

fmt 字串 意義
'r^--' 紅色 + 上三角形標記 + 虛線
'go-' 綠色 + 圓圈標記 + 實線
'b--' 藍色 + 無標記 + 虛線
'r+' 紅色 + 加號標記 + 無連接線
'c-.' 青色 + 無標記 + 點虛線

若只指定標記而省略線型（如 'r+' ），資料點之間不會連線；若只指定線型而省略標記（如 'b--' ），則只顯示線條而無標記。

以下為各元素的參考表：

  • 顏色（Color）：使用單個字母表示顏色，例如 'r' 表示紅色，'b' 表示藍色。
  • 標記（Marker）：表示每個數據點的標記形狀，例如 '^' 表示上三角形，'o' 表示圓圈。
  • 線型（Line Style）：表示連接數據點的線型，例如 '-' 表示實線，'–' 表示虛線。

3.2. kwarg 參數

kwarg 是 Matplotlib 中用來設定繪圖細節的參數，例如顏色、線型、標記、標籤等。

3.2.1. 常見的kwarg參數

  • color：設定線條的顏色，可以使用顏色名稱、字母代碼、色碼或 RGB 值。
  • linestyle：設定線型，如 '–' 表示虛線，'-' 表示實線。
  • marker：設定數據點的標記樣式，如 'o' 表示圓圈，'^' 表示上三角形。
  • linewidth（縮寫 lw）：設定線條寬度，數值越大線條越粗，例如 linewidth=3 。
  • markersize（縮寫 ms）：設定標記大小，例如 markersize=10 。
  • alpha：設定透明度，範圍 0（完全透明）~ 1（完全不透明），例如 alpha=0.5 。
  • label：設定線條標籤，用於圖例顯示。
  • 若 fmt 和 kwarg 設定衝突時，以 kwarg 為主。例如 plt.plot(x, y, 'r--', color'blue')= 最終會顯示藍色（kwarg 覆蓋 fmt 的紅色）。

  • 單字，如 g：color = 'lime'
  • 字母，如 g：color = 'k'

  • 用以呈現線條標籤，如 label = 'y = x^2'
  • 需搭配 plt.legend() 函式方能呈現 label

3.2.6. 其他常用函式

  • plt.figure(figsize=(寬, 高), dpi=解析度) ：建立新的圖表畫布。 figsize 的單位是英吋，例如 figsize=(10, 6) 表示寬 10 吋、高 6 吋。 dpi 為每英吋點數，預設 100。
  • plt.xlim(起始值, 終止值) / plt.ylim(起, 止) ：設定 x / y 座標範圍。
  • plt.title(字串) ：設定圖表標題。可加 fontsize 參數控制大小。
  • plt.xlabel(字串) / plt.ylabel(字串) ：設定 x / y 座標軸標題。
  • plt.legend() ：顯示 kwarg 參數裡的 label（圖例）。
  • plt.grid(True) ：顯示格線。
  • plt.tight_layout() ：自動調整子圖間距，避免標題、標籤被裁切。

4. 中文問題

  • 在使用 Python 進行資料視覺化時，如果想要顯示中文（如標題、標籤或圖例中的文字），有時會遇到字型問題，導致中文無法正常顯示。
  • 這是因為 Matplotlib 預設的字型不支援中文字符，因此我們需要手動指定一個支援中文的字型，並解決負號顯示問題。
  • 這類指令無需特意記憶理解，只需在每次需要時上網查詢並複製貼上即可。

4.1. 在 PyCharm 中使用中文

PyCharm 中顯示中文的方法主要分為兩步：

  1. 指定字型，使其支援中文。
  2. 解決負號在座標軸上顯示的問題，這是 Matplotlib 中常見的一個問題，當顯示負數時，負號會被當作特殊符號處理。

4.1.1. 範例

1: # 解決中文問題
2: plt.rcParams['font.sans-serif'] = ['Arial Unicode MS'] # 步驟一（替換系統中的字型，這裡用的是Mac OSX系統）
3: plt.rcParams['axes.unicode_minus'] = False  # 步驟二（解決座標軸負數的負號顯示問題）

plt.rcParams 是 Matplotlib 的全域設定字典，可以修改各種預設行為：

  • font.sans-serif ：指定無襯線字型的優先清單，Matplotlib 預設字型不支援中文，所以要換成有中文的字型。Mac 系統可用 'Arial Unicode MS' ，Windows 可用 'Microsoft JhengHei' （微軟正黑體）。
  • axes.unicode_minus ：設為 False 時，座標軸的負號會用普通的減號 (-) 顯示，而非 Unicode 的 minus 符號（某些中文字型不支援該符號，會顯示為方塊）。

5. Legend

在資料視覺化過程中，圖例（Legend）是一個非常重要的元素，特別當你繪製多條線或多組資料時。圖例可以幫助讀者理解每條線或每組資料所代表的意義。在 Matplotlib 中，我們可以使用 plt.legend() 函式來添加圖例，並自定義圖例的位置。

5.1. plt.legend() 基本語法

  • plt.legend([label1, label2, …])：這個函式用來為每條線添加標籤。標籤的數量應與圖中繪製的線條數一致。
  • loc 參數：用來指定圖例的位置。常用的位置選項有：
    • "upper left"：左上角
    • "upper right"：右上角
    • "lower left"：左下角
    • "lower right"：右下角
    • "best"：Matplotlib 會自動選擇最佳位置，避免與圖形重疊。

5.2. 範例

 2: import numpy as np
 3:

 5: plt.clf()
 6: plt.plot(x, np.sin(x))
 7: plt.plot(x, np.cos(x))
 8: #加入圖例
 9: plt.legend(["sin", "cos"], loc="upper left")

7. 長條圖 (Bar Chart)

在 Matplotlib 中，長條圖有兩種常見形式：垂直長條圖和水平長條圖，分別使用 plt.bar() 和 plt.barh() 函式來繪製。

7.1. 語法

plt.bar( x座標資料, y座標資料 [, 參數1, 參數2, ...] )
plt.barh( x座標資料, y座標資料 [, 參數1, 參數2, ...] )

plt.bar() 繪製垂直長條圖， plt.barh() 繪製水平長條圖。常用參數如下：

  • width（bar）/ height（barh）：長條的寬度，預設為 0.8。
  • color：長條的填充色，可用單一顏色或顏色 list（為每根長條分別指定）。
  • edgecolor：長條的邊框顏色。
  • alpha：透明度，0~1 之間。
  • align：對齊方式，='center'= （預設，長條置中於 x 座標）或 'edge' （左邊緣對齊 x 座標）。
  • label：圖例標籤，搭配 plt.legend() 使用。

7.2. 範例

 1: import matplotlib.pyplot as plt
 2: import numpy as np
 3: 
 4: objects = ('Python', 'C++', 'Java', 'Perl', 'Scala', 'Lisp')

 6: 
 7: plt.barh(objects, performance, align='center', color = ['b','g','r','c','m','y'], alpha=0.5)
 8: plt.xlabel('Usage')

8. 圓餅圖 (Pie Chart)

圓餅圖（Pie Chart）是一種常用的視覺化工具，用來展示各部分在整體中所佔的比例。Matplotlib 提供了強大的 plt.pie() 函式，能夠輕鬆製作出美觀的圓餅圖。

8.1. 語法： 

plt.pie( 比例列表 [, 參數 1, 參數 2, ...] )

8.2. 參數：

  • colors：設置每個部分的顏色，使用 list 形式，例如 ['red', 'blue', 'green']。
  • labels：設置每個部分的標籤名稱，使用 list 形式。
  • explode：設置部分的突出效果，數值越大，部分突出越明顯，使用 list 形式。
  • autopct：自動顯示每個部分的百分比，格式可以為 '%3.2f%%' 表示顯示到小數點後兩位。
  • startangle：設置繪製的起始角度，預設為 0 度。
  • plt.axis('equal')：確保圖形為正圓形。
  • plt.legend(loc='位置代碼')：為圖表添加圖例，並設定圖例的位置。

10. 文字註解: plt.text()

在資料視覺化過程中，添加文字註解可以幫助讀者更直觀地了解數據的具體數值或特殊位置。在 Matplotlib 中，我們可以使用 plt.text() 函式來將文字註解放置在圖表上的指定位置。這是一個非常實用的工具，尤其是在展示具體數據點或強調特定資訊時。

10.1. 語法

plt.text(x相對座標, y相對座標, '文字字串', [其它參數])

10.2. 常用參數

  • fontsize：設定字體大小，例如 fontsize=12 。
  • color：設定文字顏色，例如 color'blue'= 。
  • fontweight：設定字體粗細，如 'bold' 、 'normal' 。
  • ha（horizontalalignment）：水平對齊方式。
    • 'left' ：文字左邊緣對齊指定的 x 座標。
    • 'center' ：文字中心對齊 x 座標。
    • 'right' ：文字右邊緣對齊 x 座標。
  • va（verticalalignment）：垂直對齊方式。
    • 'top' ：文字頂部對齊 y 座標。
    • 'center' ：文字中心對齊 y 座標。
    • 'bottom' ：文字底部對齊 y 座標（預設值）。
    • 'baseline' ：文字基線對齊 y 座標。

x、y 座標使用的是「資料座標」，也就是跟你的圖表數據同一個座標系統。例如你的 x 軸範圍是 0~10，那 plt.text(5, 8, '文字') 就會把文字放在 x=5, y=8 的位置。

10.3. 範例

4: y = [1, 4, 9, 16, 25, 36, 49, 64]
5: plt.plot(x, y, 'r--')
6: for x, y in zip(x, y):
7:     plt.text(x-0.2, y+0.6, '(%d, %d)' %(x, y))

11. 子圖表: plt.subplot()

Matplotlib 提供的 plt.subplot() 函式能夠方便地在一個視窗中繪製多個子圖，將整個繪圖區域劃分為多個區域進行展示。這使得我們可以有效利用圖表空間，同時展示多組不同的數據或圖表。

11.1. subplot 語法

plt.subplot(numRows, numCols, plotNum)
  • 圖表的整個繪圖區域被分成 numRows 行和 numCols 列
  • 然後按照從左到右，從上到下的順序對每個子區域進行編號，左上的子區域的編號為 1
  • plotNum 參數指定創建的 Axes 對象所在的區域
  • 如果 numRows, numCols 和 plotNum 這三個數都小於 10 的話, 可以把它們縮寫為一個整數, 例如 subplot(323) 和 subplot(3,2,3) 是相同的.

11.2. subplots_adjust 語法

plt.subplots_adjust(left=None, bottom=None, right=None, top=None, wspace=None, hspace=None)
  • left：子圖與畫布左邊緣的距離（0 ~ 1 之間的值）。
  • right：子圖與畫布右邊緣的距離。
  • bottom：子圖與畫布底部的距離。
  • top：子圖與畫布頂部的距離。
  • wspace：子圖之間的水平間距。
  • hspace：子圖之間的垂直間距。

13.2. Bokeh

  • 這是一個互動式視覺化模組，可以產生 HTML 檔案來顯示圖形。
  • 這裡只示範最簡單的範例，更多功能請參考官網Bokeh Documentation

13.2.1. 簡單範例

 1: import numpy as np
 2: from bokeh.plotting import figure, show
 3: from bokeh.io import output_file, save
 4: 
 5: N = 4000
 6: 
 7: x = np.random.random(size=N) * 100
 8: y = np.random.random(size=N) * 100
 9: radii = np.random.random(size=N) * 1.5
10: colors = [
11:     "#%02x%02x%02x" % (r, g, 150)
12:     for r, g in zip(
13:         np.floor(50 + 2 * x).astype(int),
14:         np.floor(30 + 2 * y).astype(int)
15:     )
16: ]
17: 
18: # 輸出到 HTML 檔案
19: output_file('bokehPlot.html', mode='inline')
20: # 在PyCharm環境中最好明確指定存檔路徑
21: # Windows範例:
22: #output_file('c:\path\to\your\directory\bokehPlot.html', mode='inline')
23: # MacOS範例:
24: #output_file('/Users/yourname/path/to/your/directory/bokehPlot.html', mode='inline')
25: p = figure(title="Basic Title", width=500, height=500)  # 新版可用 width/height
26: p.circle(x, y, radius=radii, fill_color=colors,
27:          fill_alpha=0.6, line_color=None)
28: show(p) # for PyCharm IDE
29: save(p) #存檔

  • Altair 是一個基於宣告式語法的 Python 視覺化庫，使用 Vega 和 Vega-Lite 作為後端，適合用於創建交互式圖表。
  • 更多功能請參考官網https://altair-viz.github.io/

 1: import altair as alt
 2: from vega_datasets import data
 3: 
 4: cars = data.cars()
 5: 
 6: chart = (
 7:     alt.Chart(cars)
 8:     .mark_point()
 9:     .encode(
10:         x='Horsepower',
11:         y='Miles_per_Gallon',
12:         color='Origin'
13:     )
14:     .interactive()
15: )
16: 
17: # 存成 HTML
18: chart.save('altairPlot.html')
