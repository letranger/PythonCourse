** 函式(function)基本操作
*** 函式(function)的重要性
- function 為一段程式的集合，可視為一個獨立的區段。
- function 可重覆使用，因此為結構化程式語言的重要元素。 可將龐大複雜的程式分解為小問題，由多人分別以 function 解決，縮短開發時間。
- function 可區分為以下三類：
  + Python 內建 function，如: print()、len()、int()、str()...。
  + 第三方公司所開發的模組 module(多個 function 組合)。
  + 自定義 function。

** 引數(argument)的傳遞
- 每一個函式都是獨立的，所以函式只知道自己程式區域內的變數，不認識函式外的變數。
- 變數因其所宣告位置，可區分為全域變數(Global variable)、區域變數(Local variable)。
  + 全域變數：宣告在任何函式外，所有函式皆可存取。
  + 區域變數：宣告在函式內，僅函式內可存取。
- 全域變數與區域變數範例
  #+BEGIN_SRC python -r -n :results output :exports both
# 這是全域變數，所有函式都可以讀取與使用
x = 5
y = 10

def use_global():
    # 使用全域變數 x 和 y 來計算
    print("use_global:", x + y)

def use_local():
    # 這裡定義了區域變數 x 和 y，僅在這個函式中有效
    x = 20
    y = 30
    print("use_local:", x + y)

use_global()   # 使用全域的 x=5, y=10，輸出 15
use_local()    # 使用區域的 x=20, y=30，輸出 50

# 再次使用全域變數確認未受影響
print("Global variables remain:", x, y)  # 輸出 5 10
  #+END_SRC

  #+RESULTS:
  : use_global: 15
  : use_local: 50
  : Global variables remain: 5 10
*** 說明重點：
1. use_global()：函式內沒有定義 x 或 y，因此會使用函式外的全域變數。
1. use_local()：函式內重新定義了 x 和 y，這些是區域變數，只在這個函式中有效，函式外的全域變數不會受到影響。
1. 最後再次印出全域變數，確認它們仍然是原本的值。
*** 傳值與傳址
這裡要講的概念是：我傳給 function 的參數到底會不會被 function 偷偷改掉?
舉個例子:如果我在 function circle 裡把主程式傳過來的半徑改掉，那麼，原來主程式的半徑會不會跟著被改掉呢？
#+begin_src python -r -n :results output :exports both
def circle(r):
    r = 100 #我在這裡把半徑改掉
    return r*r*3.14

r = 10
print('原來的r:', r)
print('算面積：', circle(r))
print('後來的r:', r)
#+end_src

#+RESULTS:
: 原來的 r: 10
: 算面積： 31400.0
: 後來的 r: 10
有些參數可以在 function 中被修改，有些則不行，這就是傳值/傳址的差異。
- 引數(argument)的傳遞分為兩種方式，由 Python 自動判別：
  + 傳值呼叫(Call-by-Value): 參數不會被 function 修正
  + 傳址呼叫(Call-by-Reference): 參數可以被 function 修改
|--------------------------+-------------+--------+-----------------------------------|
| 引數傳遞                   | 傳遞內容      | 參數改變 | 資料型別                            |
|--------------------------+-------------+--------+-----------------------------------|
| 傳值呼叫 call-by-value     | 引數值        | 否      | bool, int, float, str, tuple, chr |
| 傳址呼叫 call-by-reference | 引數記憶體位址 | 是      | List, dict, set                   |
|--------------------------+-------------+--------+-----------------------------------|
也就是說，如果你傳進去的參數是 list，那很有可能就會被修改：
範例:

    print('name:', name,'\tscore:',score)

score = [77, 88]

print('--原來的list--')
print(score)
print('--呼叫function ccc--')
ccc(name, score)
print('--現在的list--')
print(score)

** 全域變數(Global variable)
:PROPERTIES:

前面提到 function 內的變數是區域變數，無法影響外部。但如果你真的需要在 function 裡修改全域變數，可以使用 =global= 關鍵字。
#+begin_src python -r -n :async :results output :exports both

def f1(x):
    y = x - 3       # 這裡的 y 是區域變數，和外面的 y 無關
    if y < 0:
        return 2*x+1
    return x - 1

def f2(x):
    global y         # 宣告要使用全域的 y
    y = x - 3        # 這裡會修改到全域的 y
    if y < 0:
        return 2*x+1
    return x - 1

y = -1
print(f1(1), y)   # f1 不會改到全域的 y，所以 y 仍然是 -1
print(f2(1), y)    # f2 用了 global，所以全域的 y 被改成 1-3 = -2
#+end_src

#+RESULTS:
: 3 -1
: 3 -2

#+begin_tip
注意：雖然 =global= 可以用，但過度使用全域變數會讓程式難以維護（因為不知道哪個 function 偷偷改了它）。建議盡量用參數傳遞和 return 來交換資料。
#+end_tip

*** 調和級數 :Recursion:

def harmonic_sum(n):
  if n < 2:
    return 1
  else:
    return 1 / n + (harmonic_sum(n - 1))

import ast

def sumOfList(intLst):
    total = 0
    for element in intLst:
        if type(element) == type([]):
            total += sumOfList(element)
        else:
            total += element
    return total

intStr = '[1, 2, [3, 4, [5, 6, 7]]]'

intLst = ast.literal_eval(intStr)

print(sumOfList(intLst))

def recuMax(numList):
    if len(numList) == 2:

#+begin_src python -r -n :results output :exports both
def permute_in_place(a):
    a.sort()
    yield list(a)

    if len(a) <= 1:
        return

    first = 0
    last = len(a)
    while 1:
        i = last - 1

        while 1:
            i = i - 1
            if a[i] < a[i+1]:
                j = last - 1
                while not (a[i] < a[j]):
                    j = j - 1
                a[i], a[j] = a[j], a[i] # swap the values
                r = a[i+1:last]
                r.reverse()
                a[i+1:last] = r
                yield list(a)
                break
            if i == first:
                a.reverse()
                return

def getPermutations(array):
    if len(array) == 1:
        yield array
    else:
        for i in range(len(array)):
            perms = getPermutations(array[:i] + array[i+1:])
            for p in perms:
                yield [array[i], *p]

*** 遞迴計算
**** 說明
寫一個遞迴 function，計算 n+(n-2)+(n-4)+... 的總和（一直加到 n-x ≤ 0 為止）。
**** 輸入
6
**** 輸出

**** solution :noexport:
#+begin_src python -r -n :results output :exports both
def sum_series(n):
  if n < 1:
    return 0
  else:
    return n + sum_series(n - 2)

print(sum_series(6))

* yield 與 Generator
=yield= 的用法很像 =return= ，但有一個關鍵差異：=return= 會結束整個 function，而 =yield= 只是「暫停」function，等下一次被呼叫時會從暫停的地方繼續執行。

使用 =yield= 的 function 叫做 *generator function*，呼叫它不會立即執行，而是產生一個 generator object，可以用 =next()= 或 =for= 迴圈來逐步取值。
#+begin_src python -r -n :results output :exports both
def countdown(n):
    while n > 0:
        yield n     # 每次暫停在這裡，傳回 n 的值
        n -= 1

for num in countdown(5):
    print(num, end=' ')
#+end_src

#+RESULTS:
: 5 4 3 2 1

Generator 的好處是「用多少算多少」——不會一次把所有結果都存在記憶體裡，特別適合處理大量資料。

** decorator
簡單來說，decorator（修飾器）就是一個「包裝函式的函式」——它能在不修改原本 function 程式碼的情況下，幫它加上額外的功能。想像你有一個蛋糕（原本的 function），decorator 就像在外面加上一層糖霜，蛋糕本身沒變，但吃起來多了新風味。

Python 的修飾器可用來間接修改 callable object（function, method, class）的行為，但不直接改動 object 本身，其用途包括:
- 加入日誌(logging)
- 存取權限管控與身份驗證
- 加入監測function及衡量執行時間
- 限制function執行頻率
- 用快取暫存function的執行結果
*** 修飾無參數function
先看一個最簡單的例子，然後拆解它的運作流程：
#+begin_src python -r -n :results output :exports both
def uppercase(func):        # (1) 定義一個 decorator，接收一個 function 做為參數
    def wrapper():          # (2) 在裡面定義一個新的 function（叫 wrapper）
        original_result = func()        # (3) 呼叫原始 function
        modified_result = original_result.upper()  # (4) 對結果加工
        return modified_result
    return wrapper          # (5) 傳回這個加工過的 wrapper

@uppercase #以uppercase修飾greet
def greet():
    return 'Hello'

print(greet())
#+end_src

#+RESULTS:
: HELLO

上面的 =@uppercase= 放在 =greet()= 上方，效果等同於：
#+begin_src python -r -n

#+end_src
也就是說，=greet= 被「偷天換日」了——原本的 =greet= 被丟進 =uppercase()= 裡加工，出來的是一個會自動轉大寫的新版 =greet= 。

*** 修飾有傳入參數的function
若要修飾的function有帶參數，則wrapper()要改為wrapper(*args, **kwargs),這分別用來收集所有傳入的positional與keyword類參數，以tuple及dict形式儲存在args與kwargs變數裡，然後wrapper利用*與**將收集到的參數unpack後傳給原始func，如此就不會限制到參數個數。

        print(f'trace: callable function {func.__name__}, with arguments: {args}, {kwargs}')
        original_results = func(*args, **kwargs)
        print(f'trace: function {func.__name__} return results: {original_results}!')
        return original_results
    return wrapper

@trace

    return f'{name}, {line}'

#+begin_src python -r -n :results output :exports both
import time
def eval_time(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        res = func(*args, **kwargs)
        finish = time.perf_counter()
        print(f'Finished in {round(finish-start, 2)} second(s)')
        return res
    return wrapper

@eval_time
def sigma(n):
    sum = 0
    for i in range(n):
        sum = sum + i

** 拆解函式參數（Unpack）

- =*= 加在 list 或 tuple 前面：會把裡面的元素一個一個拆開，當成位置型參數（positional parameters）傳入
- =**= 加在 dict 前面：會把 key-value 拆開，當成關鍵字參數（keyword parameters）傳入

: <1, 0, 1>

** 要不要寫 return？
- =return= 與 =return None= 效果一樣，都會傳回 =None=
- 如果 function 沒有需要傳回的值，可以省略 =return= 。例如，一個只負責 =print= 的 function 並沒有任何值需要傳回，硬寫 =return= 反而很奇怪
- 小技巧：如果你的 function 是「做事」（印出、儲存、修改），通常不需要 return；如果是「算東西」（計算面積、找最大值），就需要 return 把結果傳出來

** == 與 is 的差異
- ~==~ 比較的是「值（value）」是否相等：內容一樣就是 True
- ~is~ 比較的是「身份（identity）」是否相同：必須是同一個物件才是 True（可以想成：是不是住在記憶體中的同一個地址）
#+begin_src python -r -n :results output :exports both
a = [1, 2, 3]
b = [1, 2, 3]
c = a
print(a == b)
print(a is b)
print(a == c)
print(a is c)
#+end_src

#+RESULTS:
: True
: False
: True
: True

上面的例子中，=a= 和 =b= 雖然內容一樣（都是 [1, 2, 3]），但它們是分別建立的兩個 list，住在不同的記憶體位址，所以 ~a == b~ 是 True，但 ~a is b~ 是 False。而 =c = a= 只是幫 =a= 取了一個別名，所以 =a is c= 是 True。

#+begin_tip
實用建議：一般比較資料時用 ~==~ 就好。只有在你特別需要確認「這是不是同一個物件」時才用 ~is~ （最常見的用法是 ~if x is None~）。
#+end_tip

** ABC: Abstract Base Class
C++、Java等語言都有「介面」(interface)這種本身無法建立object、卻能當成建立object template的機制。Python則可藉由ABC來實作。藉由ABC來建立class，便是可確保繼承之sub-class均有正確的特定method。

        pass

** Stack
Stack（堆疊）是一種 *後進先出*（Last In, First Out, LIFO）的資料結構。想像一疊盤子：你只能從最上面放盤子（push），也只能從最上面拿盤子（pop）。Python 有幾種方式可以實作 Stack：
*** list
- python內部以動態陣列來實作list，所以會配置比element所需更大的空間，視需要增減。故push與pop不見會需要調整大小，平均效率可達O(1)
- 但為了達到這種效率，element必須從tail做push, pop
- 若改由list的head做push,pop，則list內所有element均需位移，效率會降為O(n)
#+begin_src python -r -n :results output :exports both
a = []
a.append('eating')
a.append('sleeping')
a.append('coding')
print(a)
a.pop()
print(a)

#自head做push, pop
a.insert(0, 'drinking')
a.insert(0, 'playing')
a.pop(0)
print(a)
#+end_src

#+RESULTS:
: ['eating', 'sleeping', 'coding']
: ['eating', 'sleeping']
: ['drinking', 'eating', 'sleeping']

** Queue

- 限制之一是預設為由小到大排序

* Python 套件管理
** pip v.s. conda
*** pip or conda
- Python 的一大優勢之一便是龐大的第三方函式庫，讓使用 Python 的程式設計師可以方便地進行網路資料下載與解析、資料視覺化，甚至是大數據分析與人工智慧等工作。
- 目前用來管理這些龐大套件的工具主要有二：pip 與 Conda。
*** pip
- Pip是[[https://www.pypa.io/en/latest/][Python Packaging Authority]]推薦、用於從[[https://pypi.org/][Python Package Index]]安裝套件的工具，提供了對 Python 套件的搜尋、下載、安裝、卸載的功能。
- 若在 python.org 下載最新版本的 python，則已內建 pip 安裝套件。 Python 3.4+ 以上版本均已包括 pip 
- 該工具類似 Linux 下的 apt/yum 或 MAC 下的[[https://brew.sh/index_zh-tw][Homebrew]]。
*** conda
- Conda 是一個開源的跨平台工具軟體，它被設計作為 Python、R、Lua、Scala、C/C++、FORTRAN/ 與 Java 等任何程式語言的套件、依賴性以及工作環境管理員，特別受到以 Python 作為主要程式語言的資料科學團隊所喜愛。
- 適用平台：Windows, macOS, Linux
- 傳統 Python 使用者以 pip 作為套件管理員（package manager）、以 venv 作為工作環境管理員（environment manager），而 conda 則達成了「兩個願望、一次滿足」既可以管理套件亦能夠管理工作環境。[fn:2]
*** 兩者的共同點
- 都以 Python 撰寫
- 都是開源軟體（Conda 採 BSD 授權、pip 採 MIT 授權）
- [[http://inspiregate.com/internet/trends/74-comparison-of-five-kinds-of-standard-open-source-license-bsd-apache-gpl-lgpl-mit.html][五種開源授權規範的比較 (BSD, Apache, GPL, LGPL, MIT)]]
*** conda、Anaconda 與 Miniconda 的差異
- conda 既是一個命令列工具，也是一個 Python 套件。[fn:3]
- Anaconda 發行版會預裝很多套件，而 Miniconda 是最小的 conda 安裝環境， 一個乾淨的 conda 環境。
- pip 只用於安裝 Python 套件，而 conda 可以安裝管理任何語言的套件。
- 不一定要安裝 Anaconda 或 Miniconda，也可透過 pip 直接安裝 conda
  #+BEGIN_SRC shell
  pip install conda
  #+END_SRC

** poetry
pip 最主要的缺點在於套件的相依性。pip 在解決套件之間的版本衝突時很容易遇到困難。它不具備先進的依賴解析算法，這可能導致不穩定的環境和不可預知的錯誤。更重要的是，移除套件時，pip 只會移除該套件本身，而不會移除其他相依的套件。也因此發展出針對套件相依性更好的工具，例如 poetry[fn:25]。

** 執行緒 vs. 程序
程序(process)是系統資源分配的最小單位，而一個程序可以有很多個執行緒(thread)。

我們每次開啟一個python檔案，都是在開啟一個新的程序，而每個程序都有自己的記憶體空間，這些記憶體空間是獨立的，互不影響。那為什麼還需要去探討執行緒呢？因為執行緒是程序中最小的執行單位，當我們在一個程序中開啟多個執行緒時，這些執行緒會共享這個程序的記憶體空間，這樣就可以讓我們在同一個程序中同時執行多個任務。

** 非執行緒的程式
為了對照執行緒的程式，我們先來看一個非執行緒的程式，這個程式會依序執行三個函式，並且計算總共花了多少時間來執行這三個函式。

** 建立及執行執行緒
#+begin_src python -r -n :results output :exports both
from threading import current_thread, Thread as Thread
from time import sleep, perf_counter

def print_hello(): # 此func所需執行時間應為1秒
    for i in range(10):
        sleep(0.1)
        print(f'{current_thread().name} says HELLO!')

def print_message(message): # 此func所需執行時間應為1秒
    for i in range(10):
        sleep(0.1)
        print(f'{current_thread().name} says {message}!')

start = perf_counter()

thread1 = Thread(target=print_hello, name='Thread 1')
thread2 = Thread(target=print_hello, name='Thread 2')
thread3 = Thread(target=print_message, args=('This is Thread 3',), name='Thread 3')

thread1.start()
thread2.start()
thread3.start()

thread1.join()
thread2.join()
thread3.join()

end = perf_counter()
print(f'Time taken: {end - start:.2f} seconds')
print(f'Current thread: {current_thread().name}')
print(f'All done!')

#+end_src

上述程式中，我們建立了三個執行緒:
- thread1 和 thread2，這兩個執行緒都會執行 print_hello 函式，
- 第三個執行緒 thread3 則會執行 print_message 函式。

仔細觀察執行輸出，我們可以發現兩項重要的事項：
1. 這三個執行緒都是 *同時* 執行的，所以我們可以看到它們的輸出是交錯在一起的
2. 照理說這三個執行緒都需要 1 秒的時間來執行，但實際上卻只花了 1.05 秒，這是因為這三個執行緒是同時執行的，所以它們的執行時間是重疊的。

這就是為什麼我們需要使用執行緒的原因，因為它可以讓我們在同一個程序中同時執行多個任務，這樣就可以提高我們的程式效率。
